## 🌐 Visão Geral do Repositório / Repository Overview

### 🇧🇷 Português (Brasil)
Este repositório centraliza toda a jornada de aprendizado prático de tecnologia e Inteligência Artificial realizada no **SENAI Ourinhos**, unificando os projetos de dois eixos principais de formação:

1. **Curso Antigravity (`/agy`)**: Desenvolvimento orientado a agentes inteligentes, landing pages de alta conversão, arquiteturas web modernas, prototipagem ágil e aplicações full-stack com ferramentas do ecossistema Google Antigravity.
2. **Curso ChatGPT & Agentes de Conversação (`/gpt`)**: Construção de chatbots inteligentes, engenharia de prompts avançada, assistentes regulatórios (ANEEL), bots de atendimento ao cliente, e integração de modelos LLM em sistemas web.

### 🇺🇸 English
This repository centralizes the hands-on learning journey in technology and Artificial Intelligence carried out at **SENAI Ourinhos**, unifying projects from two core training tracks:

1. **Antigravity Track (`/agy`)**: Agent-driven development, high-converting landing pages, modern web architectures, agile prototyping, and full-stack applications powered by the Google Antigravity ecosystem.
2. **ChatGPT & Conversational Agents Track (`/gpt`)**: Building intelligent chatbots, advanced prompt engineering, regulatory assistants (ANEEL), customer service automation, and LLM integrations with web frontends.

## 🤖 Destaque Tecnológico: Google Antigravity & Agentes de IA

Todo o ecossistema e a esteira de desenvolvimento foram acelerados e orquestrados com auxílio do **Google Antigravity**, aplicando engenharia com IA responsável, testes práticos e produtividade orientada ao mercado de trabalho.

### 🧠 Agentes de IA & Skill Packs Utilizados:
- **`@orchestrator`**: Orquestrador central responsável pela organização modular, arquitetura de monorepo e integridade de arquivos.
- **`@project-planner`**: Planejamento de sprints, etapas pedagógicas e documentação estruturada.
- **`@clean-code` & `@lint-and-validate`**: Padrões de código limpo, legibilidade e manutenibilidade.
- **`@batch-operations`**: Manipulação e organização precisa e segura de múltiplos diretórios e artefatos.

## 🛠️ Como Executar os Projetos / How to Run Locally

### 1. Clonar o Repositório
```bash
git clone https://github.com/siteprofissional1/cursos-senai.git
cd cursos-senai
```

### 2. Projetos Web Estáticos (Landing Pages e Chatbots HTML)
Basta abrir o arquivo `index.html` de qualquer projeto diretamente no seu navegador, ou utilizar a extensão **Live Server** no VS Code:
```bash
# Exemplo para testar a Hamburgueria do Joselito v2:
# Abrir o arquivo: agy/projeto-hamburgueria-do-joselito-v2/index.html
```

### 3. Projetos Full-Stack / Node.js (Ex: BurgerSync)
```bash
cd agy/aula07-projeto-burguersync
npm install
npm run dev # ou executar.bat no Windows
```
