# Backend - The Ribs Hamburgueria

O projeto atual opera como uma aplicação web estática client-side de arquivo único (`index.html`), projetada para máxima velocidade de carregamento e consulta presencial em dispositivos móveis no salão.

Caso sejam integradas APIs futuras (ex: webhook de reservas, integração PDV ou sistema de pedidos), os endpoints e funções serverless ficarão alocados neste diretório.
