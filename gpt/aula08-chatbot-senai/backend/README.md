# Backend - SENAI Ourinhos Chatbot

Este diretório é reservado para futuras integrações de servidor, tais como:
- Integração com Firebase (Authentication e Firestore para armazenamento de leads/pré-inscrições)
- API Gateway para conexão com LLMs em nuvem (Google Gemini API / OpenAI API)
- Webhooks de notificação via WhatsApp/Email para a secretaria do SENAI Ourinhos

No estado atual, o projeto opera de forma 100% autônoma e otimizada no frontend (`index.html`), com motor de inteligência local em JavaScript puro, sem dependências de servidores intermediários.
