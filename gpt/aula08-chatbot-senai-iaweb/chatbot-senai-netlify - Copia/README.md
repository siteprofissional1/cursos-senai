## 🇧🇷 Português (Brasil)

### 📌 Sobre o Projeto
O **Chatbot SENAI Ourinhos** é uma aplicação web interativa baseada em **funil de decisão 100% guiado por botões** (sem necessidade de digitação de texto), projetada para oferecer uma experiência ágil, intuitiva e sem atritos na descoberta e pré-inscrição em cursos de capacitação profissional e tecnológica.

Desenvolvido utilizando o ecossistema avançado **Google Antigravity**, o projeto conta com um catálogo enriquecido distribuído em **5 grandes áreas industriais do futuro**:
1. 💻 **TI & Inteligência Artificial** (Full Stack, IA Generativa, Cibersegurança, Ciência de Dados)
2. 🤖 **Robótica & Automação Industrial** (Células Robotizadas, CLP Siemens/Rockwell, IIoT)
3. ⚡ **Eletroeletrônica & Energia Solar** (Instalações Elétricas, Energia Fotovoltaica, Comandos Elétricos)
4. ⚙️ **Mecânica de Precisão & Usinagem CNC** (Torno/Fresa CNC, Manutenção Mecânica, CAD/SolidWorks)
5. 📊 **Gestão da Produção & Logística 4.0** (Lean Manufacturing, Supply Chain, Segurança do Trabalho)

### 🚀 Destaque Tecnológico: Google Antigravity
Este sistema foi arquitetado, modelado e refinado através da plataforma **Google Antigravity**, utilizando agentes autônomos e skills especializadas que garantem:
- Código limpo, autodocumentado e performático.
- Estruturação modular padronizada (`/frontend`, `/backend`, `/documentation`).
- Rastreabilidade de prompts através de `/documentation/promptHistory.md`.

### 🧠 Agentes e Skills Utilizados
- **Agentes Antigravity:** `@frontend-specialist`, `@orchestrator`, `@project-planner`
- **Skill Packs:** `@frontend-design`, `@clean-code`, `@design-spec`, `@lint-and-validate`

### 📁 Estrutura do Repositório
```text
├── frontend/
│   ├── index.html        # Interface semântica do chatbot
│   ├── style.css         # Estilização minimalista e responsiva
│   └── app.js            # Lógica do funil, árvore de decisão e links de conversão
├── backend/
│   ├── server.js         # API Node.js para recepção de métricas e leads
│   └── README.md         # Documentação da arquitetura de backend
├── documentation/
│   ├── promptHistory.md  # Registro histórico integral de prompts da sessão
│   └── arquitetura-funil.md # Diagrama e mapa mental da árvore de decisão
├── index.html            # Ponto de entrada compatível com deploy contínuo (Netlify)
└── README.md             # Documentação bilíngue e apresentação do projeto
```

### 📲 Conversão e Atendimento Direto
Cada curso conta com botão direto para a central de atendimento no **WhatsApp do SENAI Ourinhos** (+55 14 3302-1250), gerando automaticamente a mensagem codificada com o curso escolhido.

## 🇺🇸 English

### 📌 About The Project
The **SENAI Ourinhos Chatbot** is a modern, button-driven conversational funnel web application (100% button navigation, zero manual text typing). It guides prospective students through an intuitive, friction-free journey to explore industrial training courses and trigger instant pre-enrollment via WhatsApp.

Crafted using the cutting-edge **Google Antigravity** development framework, this solution features an enriched catalog across **5 future-ready industrial domains**:
1. 💻 **IT & Artificial Intelligence** (Full Stack Web Development, Generative AI & Prompts, Cybersecurity, Data Science)
2. 🤖 **Robotics & Industrial Automation** (Robot Cells, Siemens/Rockwell PLC, Industrial IoT)
3. ⚡ **Electrical Engineering & Solar Energy** (Electrical Installation, Photovoltaic Systems, Motor Control)
4. ⚙️ **Precision Machining & CNC** (CNC Turning/Milling, Mechanical Maintenance, CAD/SolidWorks)
5. 📊 **Production Management & Logistics 4.0** (Lean Manufacturing, Supply Chain, Industrial Safety)

### 🚀 Technology Spotlight: Google Antigravity
Engineered with the power of **Google Antigravity**, ensuring clean architecture, modular component separation (`/frontend`, `/backend`, `/documentation`), and rigorous prompt traceability.

### 🧠 Agents & AI Skills
- **Antigravity Agents:** `@frontend-specialist`, `@orchestrator`, `@project-planner`
- **Skill Packs:** `@frontend-design`, `@clean-code`, `@design-spec`, `@lint-and-validate`

### 💻 Getting Started Locally
1. Clone the repository or navigate to the directory:
   ```bash
   cd "chatbot-senai-netlify - Copia"
   ```
2. Open `index.html` directly in your browser or run a lightweight local server:
   ```bash
   npx serve .
   ```
3. For the backend metrics server:
   ```bash
   node backend/server.js
   ```
